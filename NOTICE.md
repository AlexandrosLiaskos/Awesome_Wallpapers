# Notice

This repository holds two different things, with different owners.

## The code

Everything that makes the gallery work (the site in `src/`, the scripts in `scripts/`, the tests, the configuration and the data files in `data/`) is the work of this project and is released under the [MIT licence](LICENSE).

## The wallpapers

The images in `images/` are **not** covered by the MIT licence.

- They were collected from [D3Ext/aesthetic-wallpapers](https://github.com/D3Ext/aesthetic-wallpapers), unless an entry in [`data/wallpapers.yml`](data/wallpapers.yml) names another source.
- Each one belongs to the artist or rights holder who made it. This project claims no ownership of any of them.
- Where the artist is known, the entry carries a `credit`, and the wallpaper's page shows it. Most artists are not known to us. If you recognise a piece, tell us and we will add the credit.
- Names, logos and characters that appear in some wallpapers are trademarks of their respective owners.

They are shared here for personal use as desktop and phone backgrounds, as they were in the collection they come from. This project cannot grant rights to them; for any other use, ask the artist.

## Indexed collections

The gallery also shows wallpapers from other collections on GitHub, listed in [`data/sources.yml`](data/sources.yml).

- Their originals are never stored in this repository. It keeps a title, tags and measurements (size and colours) for each file, in `data/sources/`. The site shows small previews made from the files, and Download fetches the original from the collection's own repository.
- Each collection keeps its own terms, as its repository states them. This project does not change them and cannot grant rights to the wallpapers in it.
- Every wallpaper page names the collection it comes from and links to its repository.

## Credit and removal

If you are the artist or rights holder of a wallpaper here and would like it credited or removed, [open an issue](https://github.com/AlexandrosLiaskos/Awesome_Wallpapers/issues/new/choose) and say which one. No proof beyond a reasonable explanation is asked for, and a removal takes the file out of both the repository and the gallery.

The same goes for indexed collections. If you maintain one and would rather it were not in the gallery, open an issue: the collection is removed. A request about one file of an indexed collection removes that file from the gallery.
